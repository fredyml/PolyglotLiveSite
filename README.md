# Polyglot Live

> **Real-Time Two-Way Voice Translation for Windows**

Polyglot Live is an independent Windows desktop application providing real-time, bidirectional voice translation for video calls, meetings, and voice chats across Zoom, Microsoft Teams, Google Meet, and Discord.

- **Official Website:** [https://fredyml.github.io/PolyglotLiveSite/](https://fredyml.github.io/PolyglotLiveSite/)
- **Developer:** [Fredy Mendoza on LinkedIn](https://www.linkedin.com/in/fredy-mendoza-software-developer/)
- **Platform:** Windows 10 (version 1703 or later) & Windows 11

---

## Overview

This repository hosts the official marketing, informational, and documentation website for Polyglot Live, deployed via GitHub Pages.

All application purchases, plan activations, and account authentications are managed exclusively inside the Polyglot Live Windows desktop application.
